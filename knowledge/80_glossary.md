# Aviation Glossary (for the booking workflow)

Terms AERUPT uses in results and that appear in traveler questions.

| Term | Meaning |
| --- | --- |
| PNR / booking reference | 6-char alphanumeric booking code (e.g. AER1001) |
| IATA code | 3-letter airport code (CDG, LHR, HND, ...) |
| Operating airline | Airline that actually flies the aircraft |
| Cabin | Economy / Premium Economy / Business / First |
| Fare family | Set of rules attached to a price point |
| Non-stop | One flight, no landings between origin and destination |
| Direct | Same flight number, may land (technical stop) in between |
| Stopover | Intended pause on a route; a stopover at some hubs is free on long haul |
| Codeshare | One airline sells a seat on another's flight under its own number |
| E-ticket | Electronic proof of purchase; not the boarding pass |
| Boarding pass | Document used at the gate; issued by check-in |
| Curve | Rebooking window before an over-sell is published (rare) |
| Availability | Number of seats the fare system reports at a given price point |
| Class of service / fare basis | Letter code on the ticket that encodes the fare rules |
| Sprint | Same-day changes on the same route if availability exists (program-specific) |

## Units
- Baggage weights: kg worldwide, lb in the US.
- Distances: km for short/medium segments, miles for long haul in many engines.
- Prices: currency per the booking platform locale (shown on the fare card).
