## Connecting air
- A **direct flight** is one number but may make stops; a **non-stop** flight has no stops at all.
- A **layover** is a planned stop; a short, tight layover is called a **connection**. Browsing results list both.

## Airport trivia used for grounding answers
- Some cities have multiple airports (Paris: CDG + ORY; Tokyo: HND + NRT; London: LHR/LGW/STN/LCY; New York: JFK/EWR/LGA).
- Booking results from a platform return the specific airport code; if the user names only the city, the platform's default airport per route is used.
