# Booking, E-tickets & Confirmations

When a flight is booked, the airline issues an **electronic ticket (e-ticket)** and a **booking reference (PNR)** — a 6-character alphanumeric code such as `AER1001`. The booking reference is the key identifier for managing the trip: checking in, changing a seat, or cancelling.

## What the reference unlocks
- Check-in: web/mobile check-in opens 24 hours before departure (48 hours for many long-haul carriers).
- Seat selection: often included for standard seats; exit-row and preferred seats may cost extra.
- Changes: date, route, or passenger-name changes are possible but governed by the fare rules.
- Cancellation: cancelling returns the trip according to the ticket's refund rules (see refunds & cancellations).

## E-ticket basics
- An e-ticket is not a boarding pass — it is the proof of purchase. Boarding passes are issued at check-in.
- You do not need to print the e-ticket; the booking reference plus photo ID is enough for check-in.
- Ticket numbers are 13 digits and belong to a specific airline's issuing code (airline prefix, e.g. 220 for United, 016 for United? — the exact prefix varies by operating airline).

## Common booking fields
| Field | Meaning |
| --- | --- |
| Origin / Destination | IATA airport codes (e.g. CDG for Paris, LHR for London, HND for Tokyo) |
| Departure date | Local date of departure at the origin |
| Class | Economy, Premium Economy, Business, or First |
| Passengers | Number of travelers on the booking |
| Fare type | Refundable, non-refundable, or partially refundable |

## Cancelling a booking
1. Confirm the booking reference and the flight to cancel.
2. Check the fare rules first: non-refundable tickets usually cannot be refunded to cash.
3. Cancel through the booking platform; the airline releases the seat, the PNR is closed, and any refund/credit follows the fare rules.
4. Always verify the cancellation succeeded and keep the confirmation.
